## ✨ 产品简介

**CosCraft —— 专为 Cos 服手工制作者打造的 AI 参考工具**

CosCraft 是一款面向 **Cosplay 爱好者与手作娘**的智能辅助工具，帮助用户将动漫角色截图一键转化为可落地的服装制作方案。

只需上传动漫角色全身正面图（支持 JPG/PNG 格式），AI 即可：

1. 🪡 **自动识别服装层次结构**
2. 🖼️ 在 **2~3 分钟内生成专业的四视图多角度参考图**
3. 📋 输出包含 **材质选择、制作工艺及穿着顺序** 的详细制作指南

无论是初学者还是经验丰富的制作者，均可将生成的方案直接交给打版师落地制作，**大幅降低沟通成本与制版难度**。

CosCraft 将 AI 技术与 Cos 文化深度结合，让每一件还原服装的诞生变得**更高效、更精准**。
